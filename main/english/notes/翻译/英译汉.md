```
达尔文确信失去这些品味不仅会失去快乐，而且可能会损害思维能力，更有可能影响道德品质。
```

![](assets\a-l1-1.png)

**[L2]**

![](assets\l1-2.png)

```
电视是一种...的方法
电视是一种激发和传播感受的方法，在近些年的欧洲，这种连接如此多不同的人和国家的服务可能前所未有。
```

![](assets\a-l1-2.png)

* peoples and nations 民族和国家
* never before 前所未有
* serve
  * 前面是**人**：服务
  * 前面是**物**：起作用，发挥作用
* as
  * 作为
  * 像，如
  * 随着，当
  * 因为
* **中文中，表目的的部分可以先说**

>翻译基本解题步骤
>
>1. 对着英文**写汉字**，把认识的单词尽可能写下来
>2. 当有三个左右的汉语词（一个主干，或者一个词组），尽量构成一个**小句子**
>3. 把每两个小句子，连贯成通顺的**大句子**

**[L3]**

![](assets\l1-3.png)

```
我将定义他为一个个体
他被选择因为他的主要职责和生活中的压力
在道德问题上以苏格拉底方式思考的能力

我认为他是这样一个人，因为他的首要职责和生活中的压力以及在道德问题上以苏格拉底方式思考的能力而被选中。
```

![](assets\a-l1-3.png)

* consider ... as / regard ... as / define ... as
  * 把……看做；把......视为；把......定义为
* in ... way / manner / form 
  * 以 ... 的方式
