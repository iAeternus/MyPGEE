# **翻译真题练习**

## 2013 年

### 英二

#### my

```
我能从过去53年中选出一天，并且立即知道我在哪里，那天的新闻是什么，甚至那天是星期几。
自从4岁开始，我就有这个能力。
我从未对我的大脑吸收的信息数量应接不暇。
我的大脑看起来可以处理这种情况，并且简单而聪明地存储这些信息。
当我会想起悲伤的记忆，我会做任何人都会做的事——试着将它放到一边。
我不认为这对我来说更难，只是因为我的记忆更加清晰。
强大的记忆力让我的情感敏锐而生动。
我能回想起我爷爷去世的那天，以及那天之前我们去医院时的悲伤。
我也记得在同一天有百老汇海尔音乐会的开幕，它们只是都以同样的方式从我的大脑中弹出。
```

#### 优化后

```
从过去 53 年里随便给我一个日期，我都能立刻说出我那天在哪里、发生了什么、甚至那天是星期几。
我从 4 岁起就具备这种能力。
我从不觉得大脑吸收的信息量让我不堪重负。
我的大脑似乎能够轻松处理，并把这些信息井井有条地储存起来。
当我想起伤心的记忆时，我也会像任何人一样——试着把它放到一边。
我不认为仅仅因为记忆更清晰，对我来说就会更难。
强大的记忆力并不会让我的情绪变得更敏锐或生动。
我能清楚地回想起爷爷去世的那一天，以及前一天我们去医院时的悲伤。
我也记得，那一天百老汇的音乐剧《毛发》正好首演——它们都以同样的方式自然而然地浮现在我的脑海中。
```

## 2015 年

### 英二

#### my

得分：11/15

```
想象你正在一条非常熟悉的道路上开车。
可能是上班通勤、乡村之旅或回家路上。
无论哪种情况，你都对每个弯道了如指掌。
在这些旅途中，很容易对驾驶失去感知以及对途径事务视而不见。
令人困惑的是，你会认为在旅途中的时间比实际时间短。
这就是熟练驾驶现象：人们倾向于低估自己在熟悉的道路上行驶的时间。
这个现象是由我们分配的注意力导致的。
当我们会在熟悉的道路上行驶时，因为我们没有留意太多，时间似乎流逝地更快了。
到头来，当我们回忆它时，我们不会清楚的记得这次旅途，因为我们没有给予它太多注意力。
于是我们假设这趟旅途很短。
```

#### 优化后

```
设想你正行驶在一条十分熟悉的道路上。
这可能是一条你每日通勤的路线，一段进城的旅途，抑或是回家的路。
无论是哪一种，你都对其中的一弯一道了如指掌。
在这类行驶中，你很容易在驾驶时走神，对掠过的风景也近乎视而不见。
由此带来的结果是，你会感觉旅途所耗费的时间比实际更短。
这便是“熟路效应”：人们总会低估行驶一段熟悉路程所需的时间。
这种效应，是由我们分配注意力的方式造成的。
当我们行驶于熟路时，由于无需投入过多精力，便会感到时间流逝得更快。
而此后当我们回首这段旅程时，由于未曾过多关注，记忆便显得模糊不清。
于是，我们便觉得路途变短了。
```
