# **唐迟阅读课笔记**

## 阅读方法论

### 01 阅读基本方向 | 细节题

1. 先题后文，只看题干。通过题干预判文章内容
   * 第一次看只读题干，除非 4 个选项都含有相同的信息才看一下选项

2. 定位词：集齐题干中全部定位信息，才开始召唤正确答案
   * 大写、人名、地名、时间、年代、数字
   * 名词、形容词

3. 串联题干间逻辑，推测文章主题（技巧）
   * 题干中被重复提及的词，该词往往与文章主旨密切相关：出题人往往会选用重要的信息作为题干，而题干中被反复提及的词即为重中之重

4. 出题顺序和行文顺序保持一致（题文同序）

5. 阅读 = 翻译 + 句间逻辑（两种逻辑均指向重点，即考点）
   * 相反逻辑：but/yet/however，转折之后是重点
   * 相同逻辑：重复，强调重点

6. 考研阅读只考议论文，重点为作者的观点（`attribute`）
   * 抓住 **句间逻辑**
   * 抓 **感情色彩强烈的词**（adj./adv.）

7. 因果：because / since / as / for
   * since / as / for 后接句子（有谓语动词），做连词，意为 `因为`，可与 `because` 同义替换
   * derive from / originate from / stem from / result from + 原因
   * owing to / due to / **attribute to** + 原因（归因于）
   * **contribute to** + 结果（导致了 = lead to）
   * 定语从句表示因果关系（解释说明）

8. 括号里的内容要读

9. 需要回到原文，逐词比较

10. 行文套路

    * **少数派原则**：通常作者的观点与大众相反

11. **反复强调的是重点，重点是考点**

12. 黄金技巧：互为相反的选项中往往有正确答案

13. 干扰选项特征

    * 正反混淆：互为相反的选项中往往有正确答案
    * 概念偷换
    * 答非所问：不能忽略这道题问的对象是什么
    * 不同内容嫁接：凭凑的干扰项，切忌读不懂文章“连连看”
    * 非最佳答案：**反复强调的是重点，重点是考点**
    * 绝对化用词：only / must / exclusively / never / all / 最高级。往往不选，除非原文明确提到

    正确选项特征

    * 同义改写：背单词
    * 与中心思想密切相关：细节服从主旨

### 02 例证题

1. 时间对比：发生在现在的与发生在过去的往往是相反的

   * 现在：now
   * 过去：used to / ago / once / in the past

2. 标点符号的运用（传递了 **“相同”** 的逻辑思想）

   * **逗号**：两个逗号之间（插入语），或一个逗号之后（非谓语动词，名词性从句）为补充说明的部分，非主干
   * **冒号**：冒号前后从抽象到具体，冒号后面的内容解释前面的内容
   * **分号**：分号前后为并列关系，逻辑上相同

3. **例证题**：本质为对议论文的论据提问，论据是为了证明论点

   * 提问：通过举了 xxx 例子，是为了去证明/说明...

   * 标志：

     * 元素一：mention / quote / cite （一般使用被动语态）/ refer to / example / case
     * 元素二（是为了...）：illustrate / demonstrate / indicate / to show / to prove / to present / to ...	

   * **例子本身不重要**，重要的是例子所支持的观点；观点一般在例子前，有时也在例子后

   * 干扰选项的特征：就事论事（围绕例子本身来设计，迷惑性强）

     > 观点与例子的交集很好地证明了答案的正确性，这个交集不属于就事论事的范畴，例子当中不属于交集的才是就事论事

4. 做题的步骤：先判断题目类型，再定位。就目前而言，**细节题** 定位到的是答案，**例证题** 定位到的是例子往往不是答案反而是干扰项的设置依据

5. should（以及其他情态动词） 应该（理想上）：现实 != 理想

### 03 中心思想题

1. 标志：mainly about / discuss; the best title; the purpose（一般在最后一题）
2. 方法
   1. 串线法：将各段首尾句串联为一个整体，注意转折处
   2. 中心词：文中反复高频出现的词
      1. 文内同义改写：stress = pressure
      2. 中心词不止一个：正确答案必须包含所有中心词，丢三落四的选项不能选
   3. 中心句：
      1. 文章开头的提问，对它的回答，是文章的中心
      2. 独句段：一句自成一段（近 10 年，**很重要**）

### 04 作者态度题

1. 标志：attitude / deem / consider / tone（通常在最后一题，题干暗示全文中心话题）

2. 选项词汇归纳（正确选项）

   * 正面：positive / optimistic / approval / supportive

   * 负面：negative / pessimistic / disapproval / critical / 

     ​		   doubtful / suspicious / skeptical / questionable （怀疑）

   * 中立：neutral 中立的 / objective 客观的 / impartial 不偏不倚的 / disinterested 公正的

3. **小墓碑选项**：这些词一定不可能是正确答案，遇到直接排除

   * uninterested / unconcerned / indifferent 漠不关心的
   * confused / puzzled / subjective 模糊的、主观的
   * biased / prejudice / contemptuous 有偏见的、轻蔑的

4. 当作者的态度没有明确提出时：

   * 文章的框架：中心主旨，串线法
   * adj. / adv.：感情色彩鲜明的词（褒义 / 贬义）
   * 转折处：but
   * 情态动词之后 (should / must / could / need to / ought to)：应该……

5. 特别地，互为相反的两个选项中有正确答案这个规律在作者态度题中不适用

### 05 词汇题

1. 标志："???" (line / paragraph) most probably means
2. 方法：通过定位好的句子，根据逻辑关系找同义词或反义词
3. 干扰选项特征：**字面意思理解**

### 06 推理题

1. 标志：infer / learn from / imply / suggest / conclude / 

   ​		   在题干中出现 may / might / be likely to 等语气柔和的词

2. 方法

   1. 同义改写——细节 / 主旨 / 逻辑（与高考不同，千万不要加戏，直接去原文中找）
   2. 逻辑取反——推理多在转折处
