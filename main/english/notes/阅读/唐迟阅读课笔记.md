# **唐迟阅读课笔记**

## 阅读方法论

### 01 阅读基本方向

1. 先题后文，只看题干。通过题干预判文章内容
   * 第一次看只读题干，除非 4 个选项都含有相同的信息才看一下选项

2. 定位词：集齐题干中全部定位信息，才开始召唤正确答案
   * 大写、人名、地名、时间、年代、数字
   * 名词、形容词

3. 串联题干间逻辑，推测文章主题（技巧）
   * 题干中被重复提及的词，该词往往与文章主旨密切相关：出题人往往会选用重要的信息作为题干，而题干中被反复提及的词即为重中之重

4. 出题顺序和行文顺序保持一致

5. 阅读 = 翻译 + 句间逻辑（两种逻辑均指向重点，即考点）
   * 相反逻辑：but/yet/however，转折之后是重点
   * 相同逻辑：重复，强调重点

6. 考研阅读只考议论文，重点为作者的观点（`attribute`）
   * 抓住 **句间逻辑**
   * 抓 **感情色彩强烈的词**（adj./adv.）

7. 因果：because / since / as / for
   * since / as / for 后接句子（有谓语动词），做连词，意为 `因为`，可与 `because` 同义替换
   * derive from / originate from / stem from / result from + 原因
   * owing to / due to / **attribute to** + 原因（归因于）
   * **contribute to** + 结果（导致了 = lead to）
   * 定语从句表示因果关系（解释说明）

8. 括号里的内容要读

9. 需要回到原文，逐词比较 

10. 行文套路

    * **少数派原则**：通常作者的观点与大众相反

11. **反复强调的是重点，重点是考点**

12. 黄金技巧：互为相反的选项中往往有正确答案

13. 干扰选项特征

    * 正反混淆：互为相反的选项中往往有正确答案
    * 概念偷换
    * 答非所问：不能忽略这道题问的对象是什么
    * 不同内容嫁接：凭凑的干扰项，切忌读不懂文章“连连看”
    * 非最佳答案：**反复强调的是重点，重点是考点**
    * 绝对化用词：only / must / exclusively / never / all / 最高级。往往不选，除非原文明确提到

    正确选项特征

    * 同义改写：背单词
    * 与中心思想密切相关：细节服从主旨
