# **政治大题**

## 马原

### 答题框架

点题 + 默写背诵原理 + “抄”材料

**举例：** 请运用唯物辩证法的相关原理，分析为何必须将“投资于物”与“投资于人”紧密结合起来？

```
答：
“投资于物”与“投资于人”紧密结合体现了唯物辩证法关于事物是普遍联系的以及矛盾同一性的原理。（第一段：点题）

唯物辩证法认为，首先，世界是一个普遍联系的有机整体，事物之间相互影响、相互制约。其次，同一性和斗争性是矛盾的两种基本属性。矛盾的同一性是指矛盾着的对立面相互依存、相互贯通的性质和趋势：矛盾的斗争性是矛盾着的对立面相互排斥、相互分离的性质和趋势。矛盾的同一性和斗争性相互联结、相辅相成。矛盾的同一性和斗争性相结合，构成亏事物的矛盾运动，推动着事物的变化发展。（第二段：默写背的原理）

“投资于物”与“投资于人”二者相辅相成。“投资于物”是“投资于人”的重要基础,而“投资于人”则为“投资于物”提供重要支撑。（第三段：“抄”材料）
```

### 启示类提问的万能模板

一般出现在考试第二问

```
我们应该坚持辩证思维，用联系的、发展的、全面的观点看问题，透过现象看本质，把握事物的本质和发展规律，找到解决问题的方法和途径。
```

```
我们要学习和运用矛盾分析法，矛盾分析方法的核心要求是善于分析矛盾的特殊性，做到具体问题具体分析。这要求我们增强问题意识，坚持问题导向，承认矛盾的普遍性、客观性，把优先解决主要矛盾作为打开局面的突破口，以此带动其他矛盾的解决。
```

```
我们要坚持一切从实际出发，充分发挥主观能动性，在尊重规律的前提下，促成事物朝有利的方向转化。推动认识和实践历史的、具体的发展。
```

### 大框架

#### 一、 唯物辩证法
1.  两大总特征
2.  对立统一规律（矛盾规律）
    * 矛盾的同一性和斗争性
    * 矛盾的普遍性和特殊性
    * 矛盾的不平衡性原理
3.  质量互变规律
4.  否定之否定规律

#### 二、 认识论
1.  实践与认识的辩证关系
2.  认识的过程与规律
3.  真理与价值

#### 三、 唯物史观
1.  社会存在与社会意识的辩证关系
2.  社会基本矛盾及其运动规律
3.  社会历史发展的动力系统
4.  人民群众是历史的创造者
