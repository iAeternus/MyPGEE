# **计组强化**

## 中央处理器

### 微程序控制器

控制器控制信号发出的方式

#### 断定法

由微指令中的“下一地址字段” + “条件判断字段” 决定下条微指令地址

常见方式：

1. **顺序法**：下一条地址 = 当前地址 + 1
2. **转移法**：
   - 无条件转移 → 直接给出目标地址
   - 条件转移 → 根据标志位（如零标志 Z、进位 C）来选择下一条地址

#### 下地址的计算方法

1. **顺序控制**：下地址 = 当前地址 + 1
2. **条件转移控制**：下地址 = 微指令字段给定地址（若条件成立），否则 = 当前地址 + 1
3. **分支表（映射法）**：根据机器指令操作码查表，得到对应微程序入口地址

### PSW

助记：**符号看 OF，大小看 CF，等于看 ZF，正负看 SF**

1. `ZF`：Zero $\rightarrow$ Equal
   * ZF = 1 $\rightarrow$ 就是 A = B
2. `CF`：Carry $\rightarrow$ 无符号数大小比较
   * CF = 1 $\rightarrow$ A < B（因为无符号数借位了）
   * CF = 0 且 ZF = 0 $\rightarrow$ A > B
3. `OF`：Overflow $\rightarrow$ 有符号数运算溢出判断
   * 有符号数比较：看 OF ⊕ SF
     * 相等 $\rightarrow$ A > B
     * 不等 $\rightarrow$ A < B
4. `SF`：Sign $\rightarrow$ 正负
   - 结果最高位 1 就是负

### MMU

将虚拟地址转化为物理地址

### 指令的寻址方式

| 寻址方式           | 有效地址        | 访存次数                    |
| ------------------ | --------------- | --------------------------- |
| 立即寻址           | $A$ 即是操作数  | 0                           |
| 直接寻址           | $EA = A$        | 1                           |
| 一次间接寻址       | $EA = (A)$      | 2                           |
| 寄存器寻址         | $EA = R_i$      | 0                           |
| 寄存器间接一次寻址 | $EA = (R_i)$    | 1                           |
| 相对寻址           | $EA = (PC) + A$ | 1                           |
| 基址寻址           | $EA = (BR) + A$ | 1                           |
| 变址寻址           | $EA = (IX) + A$ | 1                           |
| 堆栈寻址           | 隐式            | 硬堆栈不访存，软堆栈访存 1 次 |

### 指令执行流程

1. 取指（IF）：PC → MAR → 存储器 → MDR → IR
2. 间址（IDR）：如果指令采用间接寻址，需要再访问一次内存取有效地址
3. 指令译码（ID）：IR 的操作码送入控制器译码，决定要执行的操作
4. 执行（EX）：根据操作码，启动相应的运算或访存操作
5. 中断（INT）：若有中断请求且允许，则保存现场，转去中断服务程序

### 数据通路

数据通路 = **寄存器 + 运算器（ALU）+ 总线 + 存储器接口**

- PC：存储指令地址
- MAR：存储器地址寄存器
- MDR：存储器数据寄存器
- IR：指令寄存器
- ACC/通用寄存器组
- ALU：算术逻辑运算
- 总线：数据、地址、控制

数据在这些部件之间流动，**微操作** 推动数据

#### 微操作

一个阶段 = 多个微操作

例如：**取指阶段**

1. `MAR ← PC`
2. `MDR ← M[MAR]`
3. `IR ← MDR`
4. `PC ← PC+1`

每一步都是一个 **微操作**，由控制信号在某个时钟周期触发
