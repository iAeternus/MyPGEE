### 二进制运算的实际应用

* 补码 ± 补码
  * 基础运算
  * 指针差 / 相对位移（`ptrdiff_t`）
  * 有符号比较与分支（CPU 的有符号比较指令 `jg/jl/jge/jle`）
  * 符号扩展、算术移位、补码乘除
  * 环形缓冲区 / 计时器回绕（TCP 计时器回绕）（利用模运算语义）
* 无符号数 ± 无符号数
  * 基础运算
  * 地址偏移（页内偏移/段内偏移/PC+offset）
  * 长度与大小（size_t）
  * 位运算与掩码
  * 无符号比较
* 逻辑运算（与或非）
  * 标志位生成（CPU Flags）
  * 差分比较 / 翻转：CRC、加密
* 移位运算
  * 快速乘 2 的幂、快速除 2 的幂
  * 浮点数运算对阶

* bit-level 重解释
  * 类型转换：补码与无符号数互转等

### 队列

1. 数据结构：队列、循环队列、双端队列
2. 计组：流水线中的各段寄存器相当于“缓冲队列”
3. OS
   * 进程调度队列（就绪队列、阻塞队列）
   * I/O 请求队列
4. 计网
   * 路由器缓存队列（拥塞控制）
   * TCP 发送/接收缓冲区（滑动窗口）

### 排队论与吞吐量

1. 数据结构
   * 树的高度 $\rightarrow$ ASL
   * 平衡性提高吞吐
2. 计组
   * 计算机性能指标
   * 流水线吞吐，冲突导致吞吐下降
3. OS
   * 进程调度算法（FCFS/SJF/优先级调度/高响应比优先调度/时间片轮转/多级反馈队列）
   * 页置换算法（OPT/FIFO/LRU/Clock） Belady 现象（给的物理页帧越多，产生缺少的次数越大）
   * 磁盘调度算法（SCAN/LOOK）
4. 计网
   * 网络性能指标
   * 时延带宽积（吞吐能力）
   * 拥塞控制（提升整体网络吞吐）

### 状态机

1. 数据结构：所有数据结构均可看作状态机
2. 计组
   * CPU 本身就是 **同步时钟驱动的有限状态机**
   * 五段流水线状态机：取指 ID → 译码 IF → 执行 EX → 访存 M → 写回 WB
3. OS
   * 进程三状态/五状态模型
   * 银行家算法 = 不让系统进入不安全状态（避免状态机陷入死区）
4. 计网
   * TCP 四次挥手、三次握手状态转移
