目前最大的问题及解决方案

关键词：补漏、稳定度

数学
1. 计算/粗心问题 -> 总结代表常错点的核心错题，做，复盘
2. 基本概念漏洞 -> 回归张宇课本挑几个基本概念总结核心定义、常错点、典型题
3. 见到新题快速反应能力 -> 从真题或模拟卷抽取不熟的题限时训练

408
1. 小知识点查漏补缺 -> 从错题本和王道书中抓取高频考点，回忆并重新理解，做几道相关题。让LLM随机抽取错题本中知识点像我提问
2. 基本模式防遗忘 -> 经典模式定期训练（大题专项、小题计算专项）优先重复做会忘的点
另外：
恶心的pv大题和算法大题专项，这是408中为数不多最大的变数

英语
1. 翻译单词/信达雅不够 -> 与LLM柏拉图式对话，迭代翻译信达雅
2. 大作文时间控制 -> 每天一篇大作文，时间控制在35min以内
3. 小作文还没搞 -> 以最快时间专项突破小作文并总结模板
4. 其他题手感保持 -> 其他题每天做几道保持手感
另外：
总结微词表（抽象名词/连接逻辑词/动词替换/常用短语）
时刻都可以巩固现有模板和优化现有模板

政治
1. 肖八选择错误率很高 -> 每天做一套肖八选择，复盘
2. 大题还没搞 -> 大题专项：总结万能骨架，默写结构、套题练习

通用
每周复刷错题
每周找时间做完整套卷
每天把错题本导出pdf方便手机上抽短时间回炉错题
